# Axon VS Code Extension

This extension starts `axon lsp`, exposes indexing commands, and opens the local Axon Web explorer.

Settings:

- `axon.path`: path to the `axon` executable.
- `axon.projectRoot`: workspace root override.
- `axon.lspArgs`: extra arguments appended after `axon lsp`.
- `axon.webPort`: port for `axon web`.
- `axon.trace.server`: LSP trace verbosity.
